# 手機與配件管理系統規格（確認版）

確認日期：2026-09-14
Owner：Woody
模組路徑：`/product_dev/devices/`

## 目的

提供 COMART 全體同仁查找公司購買的原廠手機、手錶、耳機、眼鏡、喇叭、平板、筆電、桌機與配件，掌握目前保管人、使用狀態、借用安排及完整歷史。

## 已確認規格

- 每一台實體設備建立一筆完整紀錄。
- 三碼資產編號：手機 `Pxx`、手錶 `Wxx`、耳機 `Exx`、眼鏡 `Gxx`、喇叭 `Sxx`、平板 `Txx`、筆電 `Nxx`、桌機 `Dxx`、配件 `Xxx`；`xx` 為各類別流水號 `01–99`。類型由下拉選單選擇，編號發出後不可變更。
- 類型與首字母由 Platform Admin 維護；新類型可新增，既有編號不變。單一首字母滿 99 台時，Admin 再配置新的未使用首字母。
- 全體啟用中 Platform 使用者可查看、搜尋及新增設備；新增設備先進入「待 Admin 確認」，確認前不可移轉或退役。
- 新增設備必填：設備類型、品牌、型號或名稱、資產歸屬單位、初始保管人。序號、IMEI、採購資料與規格可稍後補齊。
- Admin 可核准資料尚未完整的舊設備；系統持續標記待補欄位。
- 保管人與申請人直接同步 Platform `users` 主表，只能選擇啟用中使用者。停權或離職帳號保留歷史姓名，但不可承接新設備或提出申請。
- Platform Admin 負責核准、核心欄位、退役、復原、類型設定及例外處理，不另建設備管理員名單。
- 目前保管人可修改日常狀態、預計可用日期及狀況備註，不可修改核心識別、採購、歸屬或退役資料。
- 狀態：可借用、使用中、維修中、遺失／遭竊、已退役。
- 借用與永久移轉使用同一申請流程；目前保管人、預定接收人或 Admin 均可發起，但雙方都必須確認。
- 暫時借用必填開始日及預計歸還日；永久移轉沒有歸還日。到期日不會自動改變保管權。
- 歸還由借用人發起，原保管人確認實際收到及設備狀況後才完成。
- 接收時必選：正常、有使用痕跡、有損壞、配件缺少；說明與照片選填。
- 接收人可接受或拒絕；拒絕必填原因。發起人在對方確認前可以取消。所有動作均保留稽核紀錄。
- 同一設備可有多筆排隊申請；日期重疊仍可送出，但顯示時段衝突，由目前保管人決定處理順序。Admin 可要求調整但不可跳過確認。
- 保管人離職、停權或無法聯繫時，必須由兩位不同 Platform Admin 共同核准強制移轉，並填寫原因。
- 移轉用途必填：借用、產品測試、生產需求、維修、其他；其他需補充說明。可選填客戶、專案或產品開案編號。
- 到期前三天、到期日及逾期後每七天提醒借用人、原保管人與 Admin；站內通知為必要管道，公司 Email 為輔助管道。
- 維修建立獨立紀錄，送修日期與原因必填；維修廠商、費用、取回日期與結果選填，歷次紀錄永久保留。
- 遺失／遭竊為獨立狀態，必填日期、原因與說明；找回後可恢復。
- 退役原因：報廢、出售、捐贈、損壞無法修復、其他。退役為可復原的保留狀態，不從歷史中刪除。
- 只有尚未啟用的錯誤或重複資料可由 Admin 永久刪除；已啟用設備永不永久刪除。
- 每年 12 月 1–31 日進行年度盤點；保管人逐台確認仍在保管、設備異常或找不到，逾期後每七天提醒本人與 Admin。
- 設備欄位包含：品牌、正式型號、規格、原廠代號、原廠序號、顏色；手機另有 IMEI1 與選填 IMEI2。
- 完整序號與 IMEI 只供目前保管人與 Platform Admin 查看；其他人可搜尋命中，但僅顯示末四碼。
- 規格採共用核心欄位加設備類型範本，並允許額外名稱／值欄位；第一版不建立 OS、電池健康、SIM、啟用鎖、測試帳號或 MDM 等動態測試欄位。
- 採購資料包含金額、原幣、國家／地區、商店／供應商、發票／收據附件及選填保固到期日。幣別限 USD、NTD、CNY、HKD、VND，保留原幣、不換匯。
- 採購金額、來源及單據不視為機密，全體登入使用者可見。第一版不串接財務系統，也不計算折舊、殘值或帳面價值。
- 資產歸屬單位沿用 Platform 部門／據點資料，但與目前保管人及實際使用地點分開。
- 實際位置為獨立欄位，預設採用保管人的 Platform 據點，移交時可更新。
- 系統先依已確認品牌與正式型號尋找官方圖片並保留來源網址及取得日期；找不到可靠來源就留白。圖片不正確時使用者可上傳實物照片替換。
- 每台設備詳情提供 QR Code，內容為資產編號與設備詳情網址；第一版只提供單張標籤列印。
- 全體使用者可看保管、借用、狀態與維修歷史；只有 Admin 可看完整欄位前後值稽核。
- 搜尋涵蓋資產編號、品牌、型號、規格、原廠代號、原廠序號、IMEI 與保管人，並支援繁中、簡中、英文及常用別名互通；搜尋時不呼叫 AI。
- 設備清單以圖片卡顯示。一般瀏覽依「可借用優先、設備類型、資產編號」排序；搜尋依「命中率、狀態、資產編號」排序。
- 每次載入 30 筆，顯示符合條件總數，可繼續載入下 30 筆。退役設備預設隱藏。
- 導覽：設備清單、待我確認（含數量徽章）、管理（僅 Admin）、右上角新增設備。
- 第一版不做獨立借用行事曆，只在詳情顯示時段、排隊與衝突。
- 現有清單 20 筆全部匯入為待確認資料。依原清單順序在各類型內從 01 編號，原流水號只留在來源備註；資產歸屬先設為東莞恆群。找不到 Platform 使用者的保管人保留原名並標記未連結。
- 原始名稱永久保留；正式品牌、型號、規格與官方圖片另行補充，不確定時不得猜測。
- 後端使用獨立 `pd_device_*` 資料表、專用私有 Storage 與專用 Edge Function，不共用或改寫 Document Finder、KMS、Quotation 或舊 CPF。

## 第一版明確排除

- MDM、GPS 追蹤、遠端控制及測試帳號管理。
- 財務帳務串接、匯率換算、折舊與殘值。
- 獨立借用行事曆、複雜預約最佳化。
- 大量標籤排版設計。
- 未經官方證據的型號、規格或圖片推定。
